# Pearl Life Script

Loader for **Pearl Life**. The preset is minimal: one keyless loadstring, no module list published.

## Loadstring

```lua
loadstring(game:HttpGet('https://raw.githubusercontent.com/StapleArmorerAxe15/combine-presets/main/pearl-life.lua'))()
```

## How to run

1. Join Pearl Life.
2. Execute the loadstring from your executor.
3. The menu builds itself after the pull completes.

## Notes

- Because the preset ships without a feature list, check the in-game menu after load to see the current module set.
- Keyless per the preset config.
- Standard warning: scripts violate Roblox Terms of Service; use an alt.
